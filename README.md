# Stock Market Price Prediction Dashboard

## Created by Spany Awasthi

### Overview
This project is an interactive dashboard that analyzes historical stock data, visualizes trends, and predicts future stock prices using machine learning.

### Features
- Stock Selection (AAPL, TSLA, GOOG, etc.)
- Year Filter
- Candlestick Chart
- 7-Day Moving Average
- 21-Day Moving Average
- 30-Day Future Prediction
- Model Confidence Score
- Dark Mode Dashboard

### Technologies Used
- Python
- Dash
- Plotly
- Pandas
- NumPy
- Scikit-learn
- yFinance

### Run Project
```bash
pip install -r requirements.txt
python app.py
